
#### Calculator Web Application

A simple Calculator Web Application built using Spring Boot, MVC Architecture, CRUD Operations, and Thymeleaf. This project was developed as a learning exercise to understand the fundamentals of full-stack web application development using Java and Spring Boot.

🚀 Features
* Perform basic arithmetic operations:
    Addition
    Subtraction
    Multiplication
    Division
* User-friendly web interface using Thymeleaf
* MVC (Model-View-Controller) architecture implementation
* CRUD operations for calculation history management
* Spring Boot backend for business logic processing
* Database integration for storing calculation records
* Validation and error handling
* Responsive and clean UI

🛠️ Tech Stack
